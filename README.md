# АВТО — Мобильная Игра-Викторина (HTML5 + Capacitor + GitHub Actions)

Мобильная игра-викторина из 10 вопросов на автомобильную тематику с процедурной 60 FPS SVG-анимацией оранжевого ретро-маслкара на фоне.

## Особенности механики
- **10 вопросов на авто-тематику**: с каждым следующим вопросом скорость автомобиля и параллакс-скроллинга возрастает с **60 км/ч** (Вопрос 1) до **300 км/ч** (Вопрос 10).
- **Ночной раунд (Вопрос 10)**: в финальном раунде автоматически наступает ночь — зажигаются звезды и полумесяц, включаются фары дальнего/ближнего света, освещающие гравийную дорогу, и рубиновый отсвет задних габаритов.
- **Финишный выезд за кадр**: после ответа на все 10 вопросов маслкар приседает на заднюю ось и стремительно уезжает за левый край кадра.
- **Синтез звука V8**: процедурный Web Audio API генератор звука двигателя V8 и звуковых эффектов ответа (без внешних аудиофайлов).

## Автосборка через GitHub Actions (`.github/workflows/build.yml`)

В репозитории настроена полная автоматическая сборка при каждом `push` в ветку `main` или `master`:
1. **Сборка Android APK**:
   - Устанавливает Node.js 20, Java 21 (Temurin) и Android SDK.
   - Инициализирует и синхронизирует проект **Capacitor Android** (`npx cap add android && npx cap sync android`).
   - Собирает готовый установочный файл `app-debug.apk` через `./gradlew assembleDebug`.
   - Загружает APK в раздел **Actions → Artifacts** (`auto-quiz-android-debug-apk`), а при отправке тега `v*` (например, `v1.0.0`) автоматически создает **GitHub Release** с прикрепленным `.apk`.
2. **Публикация в GitHub Pages**:
   - Автоматически деплоит директорию `www/` на GitHub Pages для мгновенного запуска игры в мобильном браузере или установки как PWA.
